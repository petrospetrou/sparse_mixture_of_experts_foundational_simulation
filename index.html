Routing mathematics

These are the key equations, rendered as crisp, offline SVG mathematics. No equations are needed to use the simulator.

1. Score each expert

The router computes one logit for each expert from token representation x.

2. Convert scores to probabilities

Softmax makes the eight probabilities add up to one.

3. Select the top K

Only experts in this selected set process the token.

4. Combine the selected results

This demo renormalizes probabilities over the selected experts. Actual systems can use different weighting conventions.

5. Optional balancing objective

A simple illustrative imbalance penalty: qᵢ is the fraction of expert assignments received by expert i, and N is the number of experts. The penalty is zero when loads are equal. Real architectures use different auxiliary objectives; this is not a universal MoE formula.

Scores and assignments in this simulator are illustrative. Noise and auxiliary loss typically affect training; expert capacity behavior depends on the implementation.
